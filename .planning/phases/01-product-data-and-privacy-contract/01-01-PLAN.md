<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User text -> translation provider | Raw source text leaves Echoloom only for the current translation request. |
| User text -> optional AI enhancement | Current sentence/paragraph and selected term/phrase may leave Echoloom only for the current enhancement request. |
| App runtime -> logs/analytics/traces/error reports | Operational events leave the app boundary and must remain text-free. |
| User-owned records -> database/storage | Supabase Auth/Postgres/RLS is the system of record for saved vocabulary, context, and review data. |
| Debug tooling -> production runtime | Development logging must not become a production default. |
| User deletion -> aggregate metrics | Deleted user content must not remain reconstructable through aggregate events. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | I | Logging and Analytics Boundary | mitigate | Contract must require production logs, analytics, traces, and error reports to exclude raw source text, translated private text, saved context, vocabulary history, and review-history content. |
| T-01-02 | I | Provider Strategy and Request Boundary | mitigate | Contract must require traditional MT payloads to contain only current source text plus languages, and AI enhancement payloads to contain only current sentence/paragraph plus selected term/phrase. |
| T-01-03 | I/T | Retention and Deletion Rules | mitigate | Contract must require deleting a vocabulary item to delete associated stored context and review data. |
| T-01-04 | I | Learning Quality Signals / aggregate metrics | mitigate | Contract must require aggregates to be anonymous, non-reconstructive, non-user-identifying, and free of raw text, saved context, vocabulary history, and review-history content. |
| T-01-05 | I | Debug logging controls | mitigate | Contract must require configurable debug logging to be disabled by default, explicit opt-in, environment-scoped, and not a production default. |
</threat_model>
